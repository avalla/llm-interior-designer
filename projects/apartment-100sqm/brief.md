# Brief - Apartment 100 m2

Demonstration project developed in conversation: no real survey. Every dimension is `assumed` unless stated otherwise.

## Scope

| Item | Value | Source |
|---|---|---|
| Building type | single-floor apartment, 12.5 x 8.0 m gross (100 m2) | assumed |
| Type of work | new internal layout + furnishing | assumed |
| Allowed changes | partitions and internal doors free; envelope and windows fixed | assumed |
| Starting files | none | - |
| Clear height | 2.70 m | assumed |
| Orientation | glazing to the south (y = 0), entrance and services to the north | assumed |

## Programme (from the request)

| Room | Priority | Notes |
|---|---|---|
| Bathroom, kitchen, bedroom, wardrobe, hall | essential | initial request |
| Entrance open to the living area | essential | user review |
| Night zone closed by a door | essential | user review |
| Modern style, rooms that do not feel oppressive | essential | initial request |

## Constraints

| Item | Value |
|---|---|
| TV not above, in front of or next to a window on the same wall | from the base design prompt |
| Doors must open without hitting fixtures or furniture | initial request |
